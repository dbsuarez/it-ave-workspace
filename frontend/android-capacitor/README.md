# IT Avenue Workspace - Android Capacitor Wrapper

This directory contains the Capacitor configuration for building the IT Avenue Workspace Android app.

## Prerequisites

1. **Build the web app first**: The Electron app's build output is used as the web content for the Android wrapper.
   ```bash
   cd D:\Development\itavenue-workspace\frontend
   npm run dist
   ```

2. **Install Android Studio**: Download and install [Android Studio](https://developer.android.com/studio) with the Android SDK.

3. **Install Capacitor dependencies**:
   ```bash
   cd android-capacitor
   npm install
   npx cap init
   ```

4. **Configure the production URL**: Edit `capacitor.config.ts` to point to your deployed backend URL:
   ```typescript
   server: {
     url: 'https://itavenue.yourdomain.com',
     cleartext: false,
   },
   ```

5. **Build and open in Android Studio**:
   ```bash
   npm run build
   npm run open:android
   ```

## Project Structure

```
android-capacitor/
├── capacitor.config.ts    # Capacitor configuration
├── package.json           # Capacitor dependencies
├── android/               # Android project (generated by `npx cap init`)
└── ../dist/               # Built web app (from `npm run dist`)
```

## Required Capacitor Plugins

| Plugin | Purpose |
|--------|---------|
| `@capacitor/camera` | Camera access for file uploads |
| `@capacitor/device` | Device information |
| `@capacitor/dialog` | Native dialogs |
| `@capacitor/file` | File system access |
| `@capacitor/network` | Network connectivity |
| `@capacitor/geolocation` | Location services (optional) |

## Building for Production

1. Build the web app: `cd ../ && npm run dist`
2. Sync with Capacitor: `npx cap sync`
3. Open in Android Studio: `npx cap open android`
4. Build APK/AAB in Android Studio

## Notes

- The app connects to `https://itavenue.yourdomain.com` by default. Change this in `capacitor.config.ts` to match your deployment.
- Android requires HTTPS for WebRTC (Huddle). The backend must be served over HTTPS with valid TLS certificates.
- Camera and microphone permissions are requested at runtime when first used.
