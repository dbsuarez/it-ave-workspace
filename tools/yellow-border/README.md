# Yellow Border

A tiny Windows utility that draws a click-through colored border around every monitor.

- Run `dist/YellowBorder.exe` to start it with the border visible.
- Run it again to toggle the running border.
- Left-click the tray icon to toggle the border.
- Right-click the tray icon to select a preset color, open the custom color picker, or exit.
- The selected color is remembered between launches.

Requires the .NET 8 Desktop Runtime.
